## Regras

- Arquivos em `sources/` entram **como vieram** e nunca são editados.
- Cada PDF ganha um ID estável (`VTSD-S01`, `VTSD-S02`…) — IDs não são
  reaproveitados, mesmo se um arquivo sair.
- Ao lado de cada PDF fica o texto extraído (`<arquivo>.txt`, com marcas
  de página) para busca. Em divergência, **o PDF vale**.
- Citação padrão: `[VTSD-S03 p.12]` (página do PDF).
